# Acme Widgets — Developer Setup

Welcome! Follow these steps to get a working dev environment.

1. Install dependencies: `bun install`
2. Run the test suite: `bun test`
3. Start the dev server: `bun run dev` (http://localhost:3000)

## Coding conventions

- TypeScript strict mode, no `any`
- Prefer small, pure functions
- Every endpoint needs input validation
